更新 douyin-脚本生成器 SKILL.md 的画面设计要求部分：

## 画面设计约束条件（2026-07-27 新增）

### 核心约束：峰峰单人+手机+自拍杆拍摄

所有画面设计和拍摄指导必须以峰峰**单人拍摄**为前提。

**允许的拍摄方式：**
- 第一人称（手机绑胸口/倒拿）
- 固定机位（手机放地上/台阶上当三脚架）
- 自拍杆（举高/侧前方）

**禁止推荐的拍摄方式：**
- ❌ 第三人称跟拍（跑步侧影、背影跟拍）
- ❌ 需要两个人配合的镜头（一人拍一人跑）
- ❌ 需要专业稳定器/GoPro跟拍的镜头

**替代方案对照表：**

| 原来想拍的 | 替换方案 |
|:-----------|:---------|
| 第三人称跑步侧影跟拍 | 第一人称胸口绑手机跑步视角 |
| 人脸侧写/表情特写 | 自拍杆举侧前方拍 |
| 跑鞋/膝盖特写 | 手机放地上仰角拍 |
| 远景独坐台阶 | 手机放对面地上定时拍 |
| 走向镜头 | 手机放地上固定机位，走过去 |
| 背影走远 | 手机放地上固定机位，走远 |
| 晨跑慢动作跟拍 | 不拍，改用第一人称+后期慢放 |
| 空镜/城市环境 | 标注"可AI生成"，在即梦/剪映中完成 |

**写画面设计时的自检：**
```
### 一人拍摄可行性检查
- 每个镜头峰峰一个人能拍吗？ □ 能 ✅ □ 不能（❌ 改方案）
- 第一人称镜头占比是否>50%？ □ 是 ✅ □ 否（❌ 减第三人称镜头）
- 所有固定机位是否有替代装置（地上/台阶/自拍杆）？ □ 有 ✅ □ 没有（❌ 重设计）
- 拍摄伙伴是否出现在任何镜头要求中？ □ 没有 ✅ □ 有（❌ 改）
```

## 🪙 最省Token铁则（脚本生成器适用）

**Token > 时间 > 完美。** 能用一句写清楚的，不要用十句来回折腾。

### 画面设计工作流
1. 画面设计方案用文字描述清晰即可，不在浏览器里逐帧找参考图
2. 需要AI生成空镜时 → 一次性写好所有prompt列表，让峰峰在即梦App里批量生成
3. 实拍场景标注清楚拍摄方式（第一人称/固定机位/自拍杆），峰峰跑步时顺手拍
4. 不需要在即梦网页版里逐张操作 — 出prompt列表即可

### 违规案例（2026-07-27）
在即梦网页版上：填prompt → 弹窗 → 选比例 → 关弹窗 → 等生成 → 看结果... 反复操作消耗大量token。
✅ 正确做法：一次性写好所有空镜prompt列表，峰峰在即梦App里批量生成。
