## 图① · 封面

### 📸 拍摄方案

| 要素 | 具体说明 |
|:----|:---------|
| **拍什么** | 晨跑结束后，在跑道边/公园长椅上坐着拉伸的背影。身体前倾拉大腿后侧，穿浅色速干T恤+深色短裤，背影视角。或者：在跑道起点/终点处，穿跑鞋站着，手机低角度拍脚+地面延伸的跑道。**推荐选背影拉伸**，更有"一个人在扛"的意境。 |
| **时间** | 清晨6:00-7:00，黄金一小时。自然光从侧后方或侧前方打过来。 |
| **地点** | 经常跑步的那条跑道/公园绿道，找一段有纵深感的直线路段。 |
| **角度** | 手机放在地面或矮桩上，仰拍或平拍。半身背影或全身，不要大脸/正脸。 |
| **构图** | 人物居左或居中偏下，画面右侧留1/3空间写文案。 |
| **色调** | 暖色+低饱和。后期用Lightroom或醒图：色温+10，对比度微降，曝光+0.3，加一点柔光。 |

### ✍️ 文案叠加

```
[第一行]  低谷怎么熬过来的
[第二行]  （空一行——留呼吸感）
[第三行]  朋友说了一句话  到现在我都记得
```

- **位置：** 居中偏上或居左，避免盖住人物头部区域
- **字体：** 手写体（推荐：静蕾体/汉仪润圆/方正静蕾简体），白字黑边（黑边宽度3px）
- **字号：** 第一行最大（封面主文案），第二行/第三行递减两级
- **样式：** 不要花哨特效，纯文字。如果可以做两行字颜色微调——第一行亮白，后两行略带微黄（#FFF5E6）

### 🎯 设计要点
> ✅ 背影让用户代入自己，"他经历低谷，我也可能经历过"
> ✅ "低谷"情绪标签精准 → 触达目标人群
> ✅ 不露脸降低拍摄难度，同时保持神秘感

## 图② · "2021年那阵子..."

### 📸 拍摄方案

| 要素 | 具体说明 |
|:----|:---------|
| **拍什么** | 现在（当下）在跑步的实拍：手机放在地面或矮石上，拍正面跑过来的样子（鞋子+小腿+地面轨迹），或者：手握手机自拍上半身——刚跑完，T恤领口微湿，手机举到胸口高度平拍，背景是晨光里的树/天空。**推荐鞋子+地面+跑道轨迹**，最有"在跑"的沉浸感。 |
| **时间** | 清晨6:00-7:00，有晨光但太阳刚升起不刺眼。 |
| **地点** | 同上条跑道，换个角度——拍脚下。 |
| **角度** | 手机放在地面（可以用水瓶立起来或找矮处支着），仰角15-20度拍跑过来的脚部。或者手握手机平拍上半身+背景。 |
| **构图** | 鞋子/腿部在画面下半部或右下角，左上角留空写文案。 |
| **色调** | 和封面统一暖色调，但轻微偏冷一档（色温比封面低-5）对应"回忆过去"的冷感。 |

### ✍️ 文案叠加

```
今天跑完拉伸的时候，突然想起2021年那阵子。

那一年至亲突然离世，整个人懵了很长一段时间。
什么都不想做，跑步也停了。
```

- **位置：** 左上角或居中偏左，纵向排列
- **字体：** 正文细黑体（思源黑体 Light / 苹方 细体），白色字+极细黑边或阴影
- **字号：** 较小（正文感），和封面大字形成对比
- **排版：** 段落之间空一行，自然断行，不要压到鞋子/腿部关键区域

### 🎯 设计要点
> ✅ 文字先锚定"今天"（当下），再回述"2021年"（过去） — 制造时间跨度
> ✅ "跑步也停了" 这张图就是跑步场景，形成画面与文字的反差——"现在重新跑起来了"
> ✅ 不要直接提"至亲离世"具体是谁，留白让读者自己带入

## 图③ · "人生就是列车"金句

### 📸 拍摄方案

| 要素 | 具体说明 |
|:----|:---------|
| **拍什么** | 空旷的环境景：跑道的延伸方向——一条笔直的跑道或公园步道，两侧有树/草坪，空无一人。或者：城市里的一条人少的街/河边步道。**重点是"空"、"延伸"、"远方的消失点"**。如果有铁路道口附近的人行步道更佳（呼应"列车"比喻）。 |
| **时间** | 清晨6:00-7:00，人少。或者傍晚17:00-18:00，蓝调时刻前。 |
| **地点** | 跑步路线上的一段视野开阔的直道，或者附近有条安静的河堤步道。 |
| **角度** | 手机平端，站姿正常视角，对准跑道/道路延伸方向。人物不入画，纯环境。 |
| **构图** | 画面纵深——跑道的消失点在画面中央偏上1/3处。两侧线条引导视觉向远方。 |
| **色调** | 暖色+轻微褪色感（褪色+5，饱和度-5，加一点颗粒感）。制造"回忆滤镜"。 |

### ✍️ 文案叠加

```
后来一个朋友跟我说了一段话，到现在我都记得——

"人生就是一趟列车，从生下来的始发站，
到死亡的终点站，这一路上车下车的人络绎不绝。
没有人能从一开始就陪你到最后，或早或晚。"
```

- **位置：** 居中或偏左下，文字压在跑道/道路的画面上半部或中部区域
- **字体：** 金句用楷体或仿宋（区别于正文的黑体），白字+黑边（黑边稍宽到5px保证可读性）
- **字号：** 比图②正文稍大，凸显金句分量
- **样式：** 引号不要省略。金句整体可以加一个半透明蒙版条（黑色，不透明度30%）垫在文字下方，保证浅色天空/道路上有足够对比度

### 🎯 设计要点
> ✅ 纯环境空景+金句文案 = 小红书经典"鸡汤配美景"模式，极易获赞收藏
> ✅ "空无一人"的延伸道路 = "一个人的旅程"视觉隐喻
> ✅ 引号保留 → 让读者一眼识别这是"别人说的话"，增强权威感

## 图④ · "马拉松不也一样嘛"

### 📸 拍摄方案

| 要素 | 具体说明 |
|:----|:---------|
| **拍什么** | 跑步过程中的特写：一只手握着手机/手表看配速的画面（手腕+运动手表），或者：跑鞋底踩在路面上的特写（鞋底纹路+路面质感），或者：跑完后坐在路边，手边放着一瓶水的近景。**推荐：一只手拿着手机，屏幕上显示跑步APP的"已完成XX公里"页面**（有具体数字更真实）。 |
| **时间** | 同上（一次跑步出门一起拍完所有素材） |
| **地点** | 同一跑道/公园 |
| **角度** | 手机换个手拿，另一只手拿着被拍的手。或者把手机放地上拍鞋底。 |
| **构图** | 特写（画面里只有手/手机/鞋底），背景适当虚化（手机人像模式或后期加模糊）。左下或右下留空写文案。 |
| **色调** | 恢复正常暖色调（褪色效果减回去，色温+8，鲜艳+5），制造"醒悟/明朗"感。 |

### ✍️ 文案叠加

```
当时没觉得什么，后来重新跑起来才明白，马拉松不也一样嘛。
赛道那么长，谁都不能陪你跑完全程。
有人陪一段，有人给你递水，但最后那几公里，还是得自己迈腿。
到终点的路，没人能替你走。
```

- **位置：** 文字放在背景比较干净的一侧（左上或右上），不要压到手表/手机屏幕
- **字体：** 回到图②同款细黑体，白字+阴影
- **字号：** 和图②一致
- **排版：** 段落紧凑，不空行。最后一句"到终点的路，没人能替你走"可以加粗或换行独立成一段

### 🎯 设计要点
> ✅ "马拉松"这段 — 跑步博主的核心受众最吃这一套，共鸣感最强
> ✅ 特写视角让读者感觉"他在跟我分享他跑步时想到的"
> ✅ 手表/手机上的跑步数据增加真实感，不是摆拍

## 图⑤ · 感谢 + 互动收尾

### 📸 拍摄方案

| 要素 | 具体说明 |
|:----|:---------|
| **拍什么** | 收尾的温馨日常照。推荐：晨跑结束坐在公园长椅上喝水的侧影/背影，或者：手机挡脸自拍（侧脸+微笑，背景是晨光里的树/草坪），或者：脚下草地+旁边放着跑鞋。**推荐选"坐在长椅上喝水的侧背影"** — 松弛、自然、不刻意。 |
| **时间** | 同上（跑完收拾装备时顺手拍） |
| **地点** | 跑道/公园附近的木椅或石凳 |
| **角度** | 手机用自拍模式或放在对面矮处定时拍。半身，稍侧。 |
| **构图** | 人物在画面一侧（左或右），另一侧留空写文案。视线方向朝画面外侧，不要太正。 |
| **色调** | 最暖、最亮的一张。色温+10，曝光+0.3，加一点柔光/柔焦效果。 |

### ✍️ 文案叠加

```
那个朋友教会我的，不是怎么面对失去，
而是该感谢那些陪你坐过一段的人。

你们呢，有没有谁在你低谷时说过一句特别的话？
评论区聊聊 🌿
```

- **位置：** 留空的那一侧写文案，居中排列
- **字体：** 细黑体（同图②/④）+ 最后一句"评论区聊聊"换手写体（同封面字体）
- **字号：** 正文小字，"评论区聊聊"放大一级
- **样式：** 🌿 符号保留，增加小红书感
- **配色：** 白字为主，标题/互动句用暖橙 #FF8C42 或 #FF6B35

### 🎯 设计要点
> ✅ 温暖收场，情绪闭环——从低谷回忆→被朋友安慰→自己悟到→感谢→邀请评论
> ✅ 互动引导（"评论区聊聊"）→ 提升笔记互动数据（小红书算法权重）
> ✅ "感谢那些陪你坐过一段的人" → 正向情绪收尾，读者看完暖心

## 拍摄执行清单（一次性出门完成）

出门前在家准备好：
- [ ] 运动手表满电
- [ ] 手机清理镜头
- [ ] 浅色速干T恤（白色/浅灰/浅蓝） + 深色短裤
- [ ] 跑鞋（最近常穿的那双）
- [ ] 一瓶水（当道具）

一次出门晨跑拍完全部5张：

| 拍摄时机 | 拍什么 | 对应图号 |
|:---------|:-------|:--------:|
| ① 热身/刚开始 | 手机放地面拍跑过来的脚+跑道轨迹 | 图② |
| ② 跑了一半 | 拍手表显示公里数（手+手机）| 图④ |
| ③ 跑完拉伸 | 找空旷直道拍纵深（不进人）| 图③ |
| ④ 拉伸时 | 背对镜头拉大腿后侧或弯腰（背影拉伸）| 图① 封面 |
| ⑤ 跑完休息 | 坐在长椅上喝水侧背影/半侧身自拍 | 图⑤ |

**总拍摄时长：** 跑完步多花5-10分钟即可全部搞定。
