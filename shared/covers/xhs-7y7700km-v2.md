## 📌 封面图（图1）— 三套方案

### 方案A｜晨光背影 · 一句内心的真实

| 要素 | 说明 |
|------|------|
| **图片内容** | 清晨6点左右，公园或河边跑道。45°后上方拍背影，晨光刚好打在肩膀和后背上，人物在画面下方1/3处，上方留出大片天空或树冠。**和v1方案A同一场景但不同角度（侧后方而不是正后方），远摄一点，能看到整条路延伸**，确保不是同张照片。 |
| **叠加文案（与标题互补）** | **「跑完那段路，就好」** |
| **为什么互补** | 标题说了"40岁跑了7年7700公里"（数据，事实），封面说"跑完那段路，就好"（感受，状态）— 一个讲结果，一个讲当下感受，互补不重复 |
| **色调/风格** | 暖金色晨光+低饱和度，vsco A6/A10调色，偏米白—浅橘色调 |
| **字体** | 霞鹜文楷（手写楷体）或思源宋体细体，**不用抖音类粗黑体** |
| **颜色/布局** | 白色字+柔和半透阴影，左上或靠左上，竖排或横排，字距拉开，两个短句换行 |
| **字数控制** | 7个字，不抢画面，留白为主 |

## 🎨 整体色调规范（v2微调）

| 维度 | 要求 |
|------|------|
| 主色调 | 暖色系（米白/浅橘/浅棕/奶咖）— 不变 |
| 饱和度 | -15%~-25%（比v1再降一点点，更柔和） |
| 色温 | +5~+10（偏暖半档）— 不变 |
| 颗粒 | 微颗粒（+2~+3，比v1略多一丁点，增加生活照感） |
| 对比度 | 略降对比（-5~-10）— 不变 |
| 清晰度 | +0 ~ +5，不过锐（小红书不喜欢太清晰的"工作照"） |
| 修图APP | VSCO（A6/A10/Autumn）、**Lightroom手机版**、**醒图·胶片暖调** 或 **最后一卷胶片·5219** |
| **与v1色调区别** | 整体再柔和5%，不追求"质感"，追求"随手拍的但好看的" |

## 📐 排版指引

| 维度 | 规范 |
|------|------|
| 封面文字位置 | 左上或居中偏上，留白充分（上方至少1/3画面无遮挡） |
| 封面字体 | 手写体或宋体（霞鹜文楷/思源宋体/清松手写体）/ **绝对不用抖音粗黑体** |
| 封面字色 | 白色为主，可带微暖（#FFFFFF ~ #FFF5E6） |
| 封面字阴影 | 柔光阴影（黑色15%透明度，1-2px偏移，2-3px模糊），不要硬描边 |
| 正文字体 | 思源宋体/霞鹜文楷，字号14-16，行距1.6-1.8 |
| 图片尺寸 | 统一 **3:4** 竖版（宽1242×高1660px 或 1080×1440px） |
| 文字排版（笔记正文） | 每段1-3行，段间空行，emoji点缀（🏃☀️👋），不堆砌 |

## 🎬 拍摄指引

### 拍摄时间
| 照片 | 推荐时间 | 理由 |
|:-----|:---------|:------|
| 封面A / 图3 / 图4 | **清晨5:50-6:30** | 晨光柔和，金色暖调，符合小红书氛围 |
| 封面B / 图5 | **下午4:30-5:30**（或跑完后即刻拍） | 侧暖光，跑完后自然松弛感 |
| 封面C | **清晨或黄昏** | 道路纵深+光影对比 |

### 拍摄地点
| 地点 | 用途 | 说明 |
|:-----|:------|:------|
| 你常跑的公园/河堤/绿道 | 封面ABC + 图3图4 | 选一段光线好的，和v1不同角度/不同段 |
| 路边长椅/花坛 | 封面B | 跑完坐下来的自然动作 |
| 一段有纵深的路 | 封面C | 路延伸向远处，有光线透入 |

### 穿搭建议
| 项目 | 建议 | 说明 |
|:-----|:------|:------|
| 跑步上衣 | **你平时穿的那件**（不特意换） | 真实感 > 搭配感 |
| 跑鞋 | 最常穿的那双（有磨损更好） | 图2可以用来拍 |
| 颜色 | 素色即可，浅灰/白/浅蓝/深灰 | 不抢视觉焦点 |
| 帽子（可选） | 可以戴，日常跑步习惯即可 | 更有"真实跑步"感 |

### 拍摄方式
| 需要 | 方式 | 提示 |
|:-----|:------|:------|
| 背影（封面A / 图4） | 让别人帮忙拍，或自拍架+定时 | 不用回头，往前走自然些 |
| 坐姿（封面B） | 自拍架/让别人拍 | 低头或看远方 |
| 远景背影（封面C） | 让别人站远处拍 | 人小景大 |
| 空镜（图3） | 自己随手拍 | 不用预设，跑着跑着看到一个好看的光影就拍 |

## 📋 和v1的关键区别总结

| 维度 | v1（旧版） | v2（新版） |
|:-----|:-----------|:-----------|
| 封面文案 | 「跑了7年｜7700公里」「40岁｜还在跑」「不跟谁比｜慢慢来」 | **「跑完那段路，就好」「不想说话的时候」「就这一段路是自己的」** |
| 文案规则 | 与标题可重复 | **必须互补不重复** |
| 照片 | 晨光背影/跑鞋特写/侧脸慢跑 | **不同角度/不同场景/不同构图** |
| 图2小字 | 「7700，7年，不多不少」 | **「一年一千，不难。」**（弱化精确数字，强日常感） |
| 图3文案 | 「这条路，跑了7年」 | **「每天就一段路，耳机一塞」** |
| 图4穿衣 | 亮色跳出背景 | **日常穿着** |
| 图5表情 | 微笑看镜头 | **不看镜头，不刻意笑** |
| 整体调性 | "有品质的生活记录" | **"随手拍下来的真实生活"** |
