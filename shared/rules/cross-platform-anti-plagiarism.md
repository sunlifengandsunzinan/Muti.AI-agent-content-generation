# 跨平台反抄袭规则文件

## 生效时间
2026-07-24
## 适用对象
所有涉及抖音+小红书双平台内容发布的子Agent（脚本生成器、封面标题官、素材管家、情报站、每日简报）
## 维护者
总助

---

## 一、为什么需要这个规则

峰峰在抖音（「40了，喝完话不多，跑完话多」）和小红书（同名定位新号）两个平台运营同一套内容定位——「40岁普通人慢跑时和自己说的话」。

两个平台共享同一套素材/感悟/人设，但必须保证**不被任何平台判定为抄袭/搬运**。两个账号是同一人运营，这是原创内容多平台分发，不是抄袭。但平台的指纹检测不会管你是不是同一人，只看内容指纹相似度。

**核心原则：同一个人讲同一件事 ≠ 抄袭。但同一段音轨+画面反复用 = 被平台判搬运。**

## 二、抖音/小红书抄袭判定指标

### 2.1 抖音判定体系

| 检测维度 | 检测方式 | 红线阈值 | 备注 |
|:---------|:---------|:---------|:-----|
| 画面指纹 | 视频帧级哈希比对 | 连续≥5帧完全一致 → 标记 | 包括色调/构图/曝光 |
| 音频指纹 | 音轨波形+频谱比对 | 波形相似度>70% → 标记 | 即使降噪/变调也能检测 |
| 编辑时间线 | 剪辑节奏/转场/字幕出现时间戳 | 时间线相似度>80% → 人工复核 | 同一个剪辑模板也会被比中 |
| 标题+正文 | NLP相似度计算 | 标题相似度>90%+正文>60% → 低质打标 | 跨账号/跨平台辅助判定 |
| 同设备/同IP | 设备指纹+网络环境 | 同一设备发两个不同号内容相似 → 关联标记 | 主要在同时操作时触发 |

### 2.2 小红书判定体系

| 检测维度 | 检测方式 | 红线阈值 | 备注 |
|:---------|:---------|:---------|:-----|
| 图片指纹 | 图片感知哈希 | 图片一致 → 标记为搬运 | 去水印/裁剪/加滤镜不影响哈希匹配 |
| 视频指纹 | 与抖音类似但数据库小型 | 比对抖音数据库的延时较长 | 小红书跨平台检测不如抖音严格 |
| 文案相似度 | NLP句子向量比对 | 文案相似度>85% → 标记 | 包括"分别检测"特征 |
| 话题标签重叠 | 标签组合一致性 | 全部标签一致 → 辅助判定 | 不单独触发但辅助权重 |

### 2.3 关键红线总结

| 行为 | 风险 | 原因 |
|:-----|:----:|:-----|
| 同一段视频文件去水印→发两平台 | ❌ 高 | 画面指纹+音轨指纹完全匹配 |
| 同一段配音+换画面→发两平台 | ❌ 高 | 音频指纹>70%匹配后被标记 |
| 同一脚本+重录音+重拍画面→发两平台 | ✅ 低 | 画面指纹+音频指纹均不同 |
| 同主题感悟+不同讲法+不同画面→发两平台 | ✅ 几乎无风险 | 跨平台指纹不匹配 |
| 同一段文字脚本→改开头结尾→两平台各录各的 | ✅ 低 | 核心内容一致，但指纹检测无法判定"同一个人写的同段话" |

## 三、每发一个视频前必须检查

### 检查项A：音频检查
- [ ] 抖音版和小红书版的**音频波形是否相同**？
- [ ] 两版配音是否是**两次独立录制**（不同时间/不同语气/不同环境）？
- [ ] 如果使用同一段配音 → ❌ 必须重录

### 检查项B：画面检查
- [ ] 两版的视频素材是否有**连续≥3段完全相同的片段**？
- [ ] 是否使用了**同一个剪辑文件**改后缀名发两个平台？→ ❌ 禁止
- [ ] 可以用**同一次出门跑步的素材**，但抖音版用A机位/前半段，小红书版用B机位/后半段
- [ ] 核心原则：**同一事件，至少2组画面**。出门拍一次，但用不同角度/不同帧

### 检查项C：脚本检查
- [ ] 抖音版和小红书版脚本正文是否**一模一样**？
- [ ] 是否需要**≥20%的本地化改动**？（建议：开头/结尾各改一句+语气适配平台）
- [ ] 抖音版的情绪曲线（压低声音/神秘感/反问踢球）是否不等于小红书版？

### 检查项D：标签检查
- [ ] 抖音标签池 vs 小红书标签池是否有**明显差异**？
- [ ] 禁止：两平台打完全一样的5个标签

### 检查项E：直接禁用的操作
- [ ] ❌ 从抖音下载视频→去水印→直接发小红书（这是找死）
- [ ] ❌ 同一个.mov/.mp4文件改名传两个平台（文件指纹完全一致）
- [ ] ❌ 复用了同一段配音+画面但声称是"两个视频"（音轨指纹检测跨平台）
- [ ] ❌ 峰峰在两个手机上同时登录两个账号发同一个视频（同设备指纹+同IP+同内容=三连击）

## 四、安全发布操作流程

### 标准流程（推荐）

```
抖音版：                       小红书版：
① 出门跑一次，主拍正面/侧近  ① 同一次出门，副拍背影/远景/环境
② 到家录配音A（压低声音版）  ② 到家录配音B（日常聊天版）
③ 剪A版（峰峰主镜头+脚本A）  ③ 剪B版（环境镜头为主+脚本B）
④ 抖音#跑步 #慢跑发布        ④ 小红书#跑步日常 #40岁运动发布
```

### 省成本流程（也安全）

```
① 出门跑一次，多角度拍（主镜头+备镜头）
② 写出脚本（核心段落不变）
③ 录第一版配音（抖音情绪）
④ 剪抖音版
⑤ 隔一天（或至少2小时后）
⑥ 读一遍脚本，改开头/结尾各2句话 → 成为小红书脚本
⑦ 录第二版配音（小红书语气）
⑧ 用备镜头素材剪小红书版
⑨ 分天分平台发布
```

## 五、标签建议

### 抖音标签池（推荐）
主标签：`#跑步 #慢跑 #晨跑 #跑步治愈 #坚持跑步`
扩展标签：`#跑步日常 #中年跑者 #跑步心得 #跑步技巧`
禁止：`#跑步日常 #运动打卡`（小红书高频标签）

### 小红书标签池（推荐）
主标签：`#跑步日常 #40岁运动 #慢跑感悟 #运动打卡 #中年健身`
扩展标签：`#中年人跑步 #跑步治愈自己 #晨跑日常 #元气生活`
禁止：`#跑步 #慢跑`（抖音高频标签）

### 交叉检查
两个平台标签组合中，**最多共享1个标签**，建议0共享。

## 六、异常处理

### 如果被平台判定非原创
1. ❌ 不申诉（申诉会让你承认两个号都是你）
2. ✅ 删除小红书上那个被判定视频
3. ✅ 隔3天重新用独立素材发
4. ✅ 下次发布前检查更具模板检查

### 如果两个账号被关联
目前抖音和小红书不会主动跨平台关联账号，除非：
- 两个手机同时登录同一个WiFi发内容
- 剪辑软件导出时保留了相同的文件元数据
- 使用了同一个手机号/邮箱绑定的第三方登录
- **建议：** 两个账号不要在同一台手机/电脑上同时登录发视频

## 七、子Agent执行规则（各自参考）

### 脚本生成器
产出双平台脚本时：
- 抖音脚本 → 保存到 `shared/scripts/`
- 小红书脚本 → 保存到 `shared/scripts/xhs-{名称}.md`
- 必须标注：**正文改动率 ≥20%**（字数比）
- 不通过 → 打回

### 封面标题官
产出双平台封面时：
- 抖音版：纸箱大字/数字标题/悬念式
- 小红书版：真人照片+文艺排版/情绪海报风格
- 封面文字不可复用同一个文案

### 素材管家
标注素材来源平台：
```json
{
  "source": "douyin" | "xiaohongshu" | "shared",
  "shotSession": "20260724-01"  // 同一次出门的同一session
}
```
同session素材 → 提醒封面标题官双版必须不同组合

### 情报站
双平台数据对比时分别评估：
- 抖音数据 + 小红书数据 在报告中分开但不对比
- 不在报告中写"两个平台数据对比"（防止数据混用）

## 八、规则更新

本文件由总助维护。以下情况需要更新：
1. 抖音/小红书更新原创判定规则
2. 峰峰被任何平台判定非原创
3. 新增平台（如视频号/快手）
4. 子Agent在检查中发现了规则没说清楚的情况

*本规则基于抖音/小红书当前的公开政策+创作者经验总结，不保证完整覆盖所有检测维度。最安全的做法永远是多拍一组素材、重录一次配音。*
