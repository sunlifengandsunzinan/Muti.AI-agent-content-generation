## 画面类型判定 → **E-纯画面+文字 + A-跟拍跑动 + C-走路边走边说 混合型**

**判定理由：**
- 脚本核心是"前3年vs后4年"的对比——这条的情感驱动**不来自面部表情，来自两段不同状态的画面混剪**
- 两个完全不同的跑步状态直接对比，比一个人坐着说"我变了"更有冲击力
- A型（跟拍跑动）和C型（走路边走边说）过去5条用得很多→ **但这次A和C不是主画面，是混剪素材点缀，不是主场景**
- **主场景是E型**（纯画面+文字对比拼接）——这在账号最近视频中几乎没用过

## 核心设计理念：两幕对比结构

这条不靠峰峰对着镜头说，而是靠**两段完全不同的跑步画面**直接对比：
- **前3年（0-4秒）** → 画面：年轻时拼命跑、看表、喘气
- **后4年（4-12秒）** → 画面：慢慢跑、停下来、放松

**峰峰只需要拍动作画面 + 后期配音叠上去。**
不需要对口型的口播镜头。

## 一、运镜和机位

| 时间段 | 画面来源 | 机位 | 运镜 | 内容 |
|--------|---------|------|------|------|
| 0-2秒 | **素材拼接** | 手机架路边/支架，低角度（约20cm高） | 固定机位 | 峰峰从远处跑向镜头→跑过镜头（侧身中景） |
| 2-4秒 | **素材拼接** | 手机架跑道上，平视 | 固定机位 | 峰峰边跑边低头看手表（中景） |
| 4-6秒 | **新拍** | 手机架路边/支架，低角度 | 固定机位 | 峰峰以慢速从远处跑近→到镜头前**放慢脚步停下** |
| 6-8秒 | **新拍** | 手机架在林荫道/跑道旁，低角度 | 固定机位 | 峰峰**停住不动**，站在原地，平视前方 |
| 8-10秒 | **新拍** | 手机切换前摄像头自拍 | 手持正面 | 峰峰站定在道路上，**微微摇头**（自嘲） |
| 10-12秒 | **新拍** | 手机切换后摄像头，架路边 | 固定机位 | 峰峰**转身，慢步走远**（背影渐渐变小） |

### 关键设计理念

- **不口播、不前摄像头说话** — 全程不需要对口型，后期配音覆盖
- **0-4秒的素材用现有跑步片段** — 如果之前拍过侧身/正面跑步的素材，直接剪过来用
- **4-12秒全部新拍** — 一个连贯的"慢跑→停下→自嘲→走远"的动作序列
- **单人可操作**：所有镜头都是手机架路边/支架上，人跑进画面。不需要第二个人

## 二、光线方案

| 时段 | 光型 | 方案 | 说明 |
|------|------|------|------|
| 0-4秒（前3年素材） | 自然光 | **正常白天的日光** — 早晨或上午（8-10点） | 素材要求：正常明亮，画面清透，符合"年轻较劲"的感觉 |
| 4-12秒（后4年新拍） | 暖暮光 | **日落前1小时（金色时段）** — 约17:30-18:30 | 暖色调侧光，形成"时间流逝"的视觉暗示 |

**为什么不拍成两天的不同时段？**
因为拍摄效率。建议：
- 选一个**晴天的下午**出发
- 先在一个**有树荫的开阔跑道/公园大道**拍后半段（4-12秒）
- 前半段（0-4秒）从**手机上已有的跑步素材**里剪辑
- 如果手头素材不够 → 同一天多跑一段补拍前半段素材

### 补光说明
- 不需要补光。所有镜头户外自然光。
- 后半段（金色时段）的暖光已经自带"后4年心境变化"的情绪暗示。

## 三、分镜视觉化

### 【0-2秒】"我跑了7年。"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | 素材拼接（已有跑步片段） |
| **画面描述** | 峰峰从远处跑向镜头（低角度侧身），跑过画面。画面顶端留白区域出现白色大字 **"7年前"**（渐显动画） |
| **角色位置** | 从画面右侧远处跑向左侧近处 |
| **镜头焦段** | 标准（手机主摄，约等效24mm） |
| **构图** | 三分法——人在右侧1/3，左侧留白给字幕 |
| **背景** | 跑道/公园/林荫道 |
| **情绪** | 动态、冲劲、速度快 |

### 【2-4秒】"前3年特别在意，每公里能快两秒都高兴。"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | 素材拼接（已有跑步片段） |
| **画面描述** | 峰峰低头看手表（定格画面或极慢动作）|
| **角色位置** | 中景，侧身或半侧身 |
| **镜头焦段** | 稍近（手机2x或裁切） |
| **构图** | 居中——手表和手臂占画面下半部 |
| **背景** | 模糊的路面/跑道 |
| **情绪** | 专注、较劲、紧张 |

### 【4-6秒】"后4年不一样了，跑得多了就想——"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | **新拍** |
| **画面描述** | 峰峰从远处**慢跑**而来（与0-2秒形成速度对比），到镜头前放慢脚步，**从跑变走再停住** |
| **角色位置** | 从远处走近→到镜头前停下 |
| **镜头焦段** | 标准（手机主摄） |
| **构图** | 三分法——人在右侧1/3走进来，左方留白。**画面顶端出现"7年后"**（淡入） |
| **背景** | 同样的跑道/公园（呼应0-2秒场景，形成对比） |
| **情绪** | 松弛、不赶、节奏慢 |

### 【6-8秒】"较劲有个啥用啊？"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | **新拍** |
| **画面描述** | 峰峰**停住站定**，站在原地平视前方。慢镜头（后期加速至0.8x），风声轻拂衣角 |
| **角色位置** | 画面中央，站定面对远处 |
| **镜头焦段** | 中全景（手机主摄，人物在画面中偏小，带环境） |
| **构图** | 居中——人站在画面正中央，**重心是"停住"这个动作** |
| **背景** | 开阔的跑道/道路/公园，远处天际线 |
| **情绪** | 停顿、静下来、金句moment |

### 【8-10秒】"放下比用力难多了。"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | **新拍** |
| **画面描述** | **切换前摄像头自拍**——峰峰站在原地，对着手机镜头**微微摇头**，带着一点自嘲的笑。**后期配音叠上** |
| **角色位置** | 手机举在胸前高度，自拍角度 |
| **镜头焦段** | 前摄像头广角（约等效26mm，带出空间感） |
| **构图** | 居中——面部在上1/3，背景在下2/3 |
| **背景** | 身后是刚才跑过的路/夕阳 |
| **情绪** | 自嘲、释然、放松 |

### 【10-12秒】"也不知道较劲跟放下，哪个更难。你发现没？"

| 视觉要素 | 内容 |
|---------|------|
| **画面来源** | **新拍** |
| **画面描述** | 峰峰**转身，慢步走远**。背影朝画面深处走，身形越来越小。画面右侧出现白色小字"你发现没？" |
| **角色位置** | 从近处走向深处 |
| **镜头焦段** | 标准中全景 |
| **构图** | 人物从画面中心出发走向纵深，消失在地平线方向 |
| **背景** | 开阔的跑道/道路，暮色或金色阳光打在身上 |
| **情绪** | 留下问题、开放式结尾、余味 |

## 四、剪辑点提示

| 时间 | 剪辑点 | 操作 |
|------|--------|------|
| 0-4秒 | **素材拼接** | 直接用已有跑步素材（如果有的话），不需要新拍 |
| 4秒处 | **核心剪辑点** | J Cut：配音"后4年不一样了"提前0.3秒进入，然后画面切到"慢跑→停住"的新拍素材 |
| 4-6秒 | **转场：动作匹配** | 0-2秒的"跑"和4秒的"慢跑"形成速度对比——两段素材建议在**同一条跑道/同一条路**拍摄 |
| 6秒处 | **节奏停** | 停住那一帧定住1-2秒不剪，给观众喘息的时间——这是全片最长的气口 |
| 8秒处 | **硬切→自拍镜头** | 从第三人称的固定机位，硬切到第一人称自拍。这个硬切就是"放下"的视觉转折 |
| 8-10秒 | **前摄像头** | 唯一一段需要峰峰"看着镜头"的画面——但**不需要对口型**，后期配音叠上 |
| 10秒处 | **切到背影** | 硬切到转身走远的背影 |
| 11.5秒 | **字幕"你发现没？"** | 画面右侧**淡入**白色小字（非黑屏大字，保持画面连续不打断感觉） |
| 12秒后 | **保持背影画面2-3秒** | 背影继续走远，画面渐隐至黑屏，作为余韵 |
| 12-14秒 | **黑屏+金句** | **黑屏+白色大字"较劲跟放下 哪个更难？"** 停留2秒，字体较小，像心里话 |

### 转场方式总结
- **0→4秒：** J Cut（声音先入）
- **4秒处：** 动作匹配转场（前段跑→后段慢跑→停住）
- **6秒处：** 顿格（定住1秒不剪）
- **8秒处：** 硬切（第三人称→第一人称自拍）
- **10秒处：** 硬切（自拍→背影）
- **12秒后：** 渐隐至黑屏

## 五、可选画面素材（如果现有素材不够，补拍清单）

如果峰峰手头没有合适的"前3年拼命跑"的素材，同一天补拍以下3个快手短片段：

### 补拍片段1（替代0-2秒素材）
- 手机架路边低角度
- 峰峰快速跑过镜头（用力摆臂、步幅大）
- 拍2次不同角度的跑动

### 补拍片段2（替代2-4秒素材）
- 手机架路边平视
- 峰峰跑近→低头看手表表情认真
- 拍1次

### 补拍片段3（4-12秒主体）
- **主场景拍摄**（后半段需要多拍几条，选最好的）

**建议拍摄顺序（高效方案）：**
1. 出门到跑道/林荫道 → 架手机拍补拍片段1和2（快速跑）
2. 休息片刻 → 用同一位置拍主场景4-12秒（慢跑→停住→前摄像头自拍→转身走远）
3. 如果时间还早，换个角度多拍一条背影

**全部拍完预计：15-20分钟**

## 七、BGM方案

| 时段 | BGM音量 | 变化原因 |
|------|---------|---------|
| 0-2秒 | 0% | 保留原始环境音——脚步声、呼吸声，真实感 |
| 2-4秒 | 渐升至5% | 极轻钢琴单音（延续"专注"感觉），几乎不可察觉 |
| 4-6秒 | 保持在5% | BGM维持，不抢画面"停下"的力量 |
| 6-8秒 | 渐降至0% | 金句"较劲有啥用"时完全留白，环境音说话给观众空间 |
| 8-10秒 | 渐升至8% | 极轻吉他泛音/弦乐长音（配合自嘲语气，不需要煽情） |
| 10-12秒 | 保持5%→渐降至0% | 走到背景深处时音量减弱 |
| 12-14秒 | 归零 | 黑屏+文字，完全无声留白，让观众自己消化 |

**BGM推荐：** 治愈向极简钢琴（如坂本龙一《Energy Flow》风格）或单音吉他泛音，整条BGM不需要旋律起伏，只是氛围托底。

## 八、注意事项

1. ✅ **单人可操作** — 所有镜头手机架路边/支架，或前摄像头自拍
2. ✅ **不需要对口型** — 全片后期配音，峰峰只需做动作和表情
3. ✅ **新旧素材对比是本片核心** — 不靠表情讲故事，靠"两段同场景不同状态"的画面直接对比
4. ✅ **同一条路拍摄** — 如果0-4秒素材是新拍的，建议和4-12秒在同一条路/同一条跑道上拍。相同的场景+不同的状态=有力量
5. ✅ **粗糙感** — 不需要清理镜头、不需要构图完美、不需要表情管理。"真实"就是这条片的滤镜
6. ✅ **脚步声和呼吸声保留** — 后期剪辑时保留原始跑步的脚步声和呼吸声，音量约10-15%，这是画面真实感的来源

## 九、与011-原生家庭拍摄方案的差异化

| 维度 | 011-原生家庭 | 本方案（跑步对比） |
|------|-------------|-------------------|
| **画面类型** | B-固定机位说（室内） | E-纯画面+文字（混剪对比） |
| **场景** | 室内近景 | 室外公园/跑道 |
| **光线** | 暖侧光+暗调 | 金色时段+自然日光 |
| **人物状态** | 坐着回忆 | 跑步+停下+走远 |
| **口播** | 6-10秒需要对口型 | **全片不需要对口型** |
| **剪辑节奏** | 慢，靠视线变化带动 | 快节奏对比+顿格停顿 |

这样两期连续发时：
- 一期内敛（坐着说家里的事）
- 一期外放（跑着说跑步的事）
- ✅ 画面类型完全不同（B vs E）
- ✅ 观众视觉体验有变化
